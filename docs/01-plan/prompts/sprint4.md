```
你是资深前端工程师。附上的 index.html 是单文件工具 PBI-Layout-Grid（Sprint 1~3 成果）。请在【此文件基础上】完成 Sprint 4，不要重写架构，不要引入依赖，保持单文件、纯前端、离线可用、全中文界面。画布固定 1280×720（已确定，不做可变画布尺寸）。

## 一、背景与问题
真实报表导入时发现：CSV 共 14 行，工具只导入 12 个。原因是 x+w>1280 或 y+h>720 的行被"整行拒绝"，只在底部一条提示里列出，用户没发现；且被拒的行不会出现在导出 CSV 中，回写时会漏改这些视觉。这是静默丢数据，必须消除。
原则：【导入 N 行 = 工具内 N 个组件 = 导出 N 行】，任何行都不能被悄悄丢弃。

## 二、功能（逐条验收）

### 4.1 越界组件照常导入
- 数值合法（X/Y/Width/Height 为非负数、宽高>0）但 x+w>1280 或 y+h>720（或 x、y 本身越界）的行：照常导入，标记为"越界"，不再拒绝。
- 越界组件在画布上的呈现：画布裁剪区之外的部分也要能看见和操作——SVG 允许溢出显示（overflow visible），画布边界线清晰；越界组件用红色边框 + 淡红填充，标签前加"⚠"。
- 列表行上显示红色"越界"小标记；状态栏显示"越界 N 个"（0 时不显示）。
- 越界组件可以正常选中、拖动、缩放、方向键移动、输入框编辑、锁定。拖动/缩放时仍受画布边界约束——但如果该组件【当前】就越界，则允许它向画布内移动，不得被边界约束"卡死"（约束规则：移动后越界程度不得比移动前更大即可）。一旦被拖进画布内，红色标记自动消失。
- 输入框校验：越界组件当前值保持原样显示；用户输入新值时，若结果仍越界且比原来更严重才拒绝，否则接受。
- 导出：越界组件原样导出（未修改则数值不变）。导出前如果仍有越界组件，弹出确认框："仍有 N 个组件超出画布，是否继续导出？"（可取消）；不阻断。
- "适应窗口"和缩放范围计算不要被越界组件撑坏：适应窗口只按 1280×720 画布计算。

### 4.2 导入核对（防静默丢行）
- 状态栏常驻显示："导入 X / CSV 共 Y 行"。X=Y 时用正常颜色，X<Y 时红色醒目。
- 仍然无法导入的行只剩：数值不是数字、负数、宽高≤0、缺 Id、Z 非整数等"数据本身损坏"的行。这些行：导入完成后弹出模态对话框（不是底部小提示），逐行列出"第 N 行 / Id / 字段 / 原因"，需用户点"知道了"关闭；状态栏同时保持红色。
- 小数取整的提示保持现状（不弹窗，沿用原有提示方式）。
- Id 重复的行：同一页内 Id 重复要保留各行并在对话框里警告"Id 重复"（回写按 Id 定位会有歧义）；不得丢弃。

### 4.3 导出一致性
- 导出行数必须等于导入行数 Y 减去"损坏行"（损坏行本来就没进工具，导出对话框里也要再提一次"原文件有 K 行未导入，导出文件不含这些行"，K=0 则不提）。
- 导出列集合、顺序、全字段加引号（空值 `""`）、UTF-8 BOM、按 Page/Z 排序规则全部沿用 Sprint 3 现状，不要改。

## 三、测试（扩展 run-tests.js，所有旧测试必须仍通过）
新增纯逻辑单测（把越界判断/约束逻辑放进 PBILOGIC 块）：
1. 越界行照常解析：样例 CSV 14 行全部进入 items，errors 为空，越界集合恰好是 Id 为 fb5630e539d444a5edb0 和 e528a60272d8eaad788e 的两行。
2. 越界判定函数：边界值（x+w=1280、y+h=720 不算越界；1281、721 算越界）。
3. 约束规则：越界组件向画布内移动被允许；向更深越界方向移动被拒绝；已在界内的组件越界移动被拒绝（原有行为）。
4. 输入框校验：越界组件输入"更不越界"的值被接受，"更越界"被拒绝。
5. 往返：导入样例 → 不改动导出 → 14 行，数值与输入一致。
6. 真损坏行（字符串数字、负数、宽高 0、Z 非整数）仍进入 errors，items 不含。
7. Id 重复保留并给出警告。

## 四、验收清单（逐条自测后在汇报中给出结果）
1. 导入样例 CSV：状态栏"导入 14 / CSV 共 14 行"（正常色），列表 14 项，状态栏"越界 2 个"。
2. 两个越界组件在画布上以红框显示并可见（溢出画布部分可见）。
3. 拖动 shape（0,0,373×1080）使其高度缩到 720 以内（或拖到 y 更小/缩小高度），红标消失，状态栏越界数减 1。
4. 越界组件撤销/重做正常。
5. 不改动直接导出：弹出"仍有 2 个组件超出画布"确认；确认后文件 14 行。
6. 人为构造一份含 1 行损坏数据的 CSV：弹出模态对话框列出该行，状态栏红色"导入 13 / CSV 共 14 行"。
7. 旧功能回归：Title 显示、Z 层次、锁定、搜索、草稿、蓝图、吸附、参考线全部正常。
8. 零页面报错（console 无 error）。
```

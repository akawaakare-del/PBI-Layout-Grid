## 一、背景与使用流程
用户先在 Power BI 里粗略放好所有视觉（位置随便堆、字段已绑好），用脚本导出坐标 CSV，导入本工具精确调整位置，导出后喂给 AI/脚本按坐标写回报表。本迭代目标：让"在一堆视觉里找到并摆准每一个"更快，并删掉重复/用不上的界面。

## 二、CSV 格式变更（输入输出同构）
新列：Page,Id,Type,Title,X,Y,Width,Height,Z
- Title：视觉标题，只读，原样透传，仅用于显示（可能为空、可能含逗号/引号/中文）。
- 空字段可能是不带引号的空值（如 `"actionButton",,"21"`，其余字段带引号），解析必须兼容；导出时所有字段统一加引号（空值写成 `""`）。当前样例 68 行中 42 行 Title 为空。表头校验要放宽：必须含 Page,Id,Type,X,Y,Width,Height，Title、Z 可选，列顺序以输入为准（现在的"表头必须完全一致"会拒绝新格式）。
- Z：整数，Power BI 的层次（越大越靠上），不一定连续（如 0、1000、2000、…），也可能重复。
- 向后兼容：输入缺少 Title 和/或 Z 列时仍可导入；缺 Title → 显示回退到 Id 前 6 位；缺 Z → 沿用"文件行序=层次"，并【禁用】层次调整按钮（带说明提示）。导出的列集合与顺序和输入完全一致（输入没有的列不要凭空新增）。
- 网页现在可修改 X/Y/Width/Height/Z；其余列原样透传。"已修改"判定、重置、导出都要覆盖 Z。
- 每页内渲染顺序按 Z 升序（Z 相同按文件行序），Z 大的盖在上面；点选取最上层。

## 三、功能（逐条验收）

### 3.1 显示 Title
- 矩形标签与左侧组件列表优先显示 Title（过长截断，不溢出矩形），其次 Type；Id 前 6 位作为次要小字。无 Title 时回退到现有显示。
- 左侧坐标窗口顶部显示选中组件的 Type / Title / 完整 Id。
- 悬停提示（hoverTip）里加入 Title。

### 3.2 层次（Z）调整
- 选中组件后，提供：置顶、上移一层、下移一层、置底（左侧坐标窗口内放 4 个小按钮；快捷键：] 上移，[ 下移，Ctrl+] 置顶，Ctrl+[ 置底）。
- 实现方式（必须）：对本页组件按当前层次排序，把选中项在序列里移动后，把【原来已有的 Z 值集合按升序重新分配】给新序列——这样不产生负数、不产生巨大新值，且只有被移动范围内的组件 Z 会变化；Z 值有重复时按行序打破平局后同样处理。
- 一次层次操作 = 一条撤销命令（涉及多个组件的 Z 变化，同一命令内撤销）。
- 画布渲染顺序、列表顺序（列表按层次从上到下排：最上层在最前）随之更新；Z 变化的组件在列表中有"已修改"标记。
- 被盖住的小组件：除列表选中外，在画布同一位置【连续再次点击】时，选中下一层的组件（循环），状态栏/提示说明"第 n/m 层"。
- 无 Z 列时按钮禁用并提示原因。

### 3.3 锁定
- 每个组件可锁定/解锁：列表行上有锁图标可点，选中后按 L 切换；批量按钮「锁定全部未选中」可不做。
- 已锁定的组件：不可拖动/缩放/方向键微调/输入框编辑/层次调整（输入框置灰）；在画布上【不拦截点击】（pointer 穿透到下层，方便处理被它盖住的组件），但仍可在列表中选中查看坐标；画布上以淡化+小锁标记显示。
- 状态栏显示"已锁定 N / 总数"。锁定状态不写入 CSV，不进撤销栈。

### 3.4 自动保存草稿与恢复
- 导入文件后，每次数据变更（防抖 500ms）把草稿存入 localStorage：原始 CSV 文本、文件名、各组件当前 {x,y,w,h,z}、锁定集合、已保存坐标点、当前页、保存时间。所有读写用 try/catch，localStorage 不可用或超限时静默降级并给一次轻提示。
- 页面打开时若发现草稿：顶部显示横幅"发现上次未完成的工作：文件名（时间）[恢复] [丢弃]"；恢复后撤销栈为空，但"已修改"标记以导入原值为基准仍然正确。导入新文件时覆盖草稿。导出后草稿保留。
- 蓝图底图不进入草稿（图片太大），恢复后需重新放入——横幅或提示里说明一次即可。

### 3.5 列表搜索
- 列表上方加搜索框：按 Title / Type / Id 子串过滤（不区分大小写，空格分词取交集），显示"匹配 n / 总数"；Esc 清空；过滤只影响列表显示，不影响画布。
- 不做悬停联动。画布点选组件时列表已会自动滚动到对应行（现有行为），保持不变；搜索过滤后选中项若被过滤掉，不要强行清除过滤，列表照常过滤即可。

### 3.6 蓝图底图
- 只接受 16:9（宽高比在 16:9 ±1% 内）的图片；不符则提示"需要 16:9 图片，当前比例 x:y"。来源：工具栏「蓝图」按钮选文件、把图片文件拖进页面（与拖 CSV 区分：按文件类型）、Ctrl+V 粘贴剪贴板里的截图。
- 以 <image> 垫在画布网格之上、组件之下，拉伸为 1280×720；工具栏/侧栏提供：显示开关、透明度滑块（默认 40%）、移除按钮。【每页独立】一张蓝图，只存内存。
- 蓝图不拦截鼠标事件，不影响吸附、选择、导出。

### 3.7 删除重复显示（按此清单执行）
- 删除画布上的角坐标标签（#cornerLabels 及 updateCornerLabels）、工具栏「显示角坐标」按钮（#btnCorners）、侧栏的「在画布上显示角坐标」复选框（#chkCorners）、state.showCorners，以及相关 CSS/测试；【保留】左上侧栏的 X/Y/宽/高输入框与顶点/中心坐标面板作为唯一的"全部坐标"窗口。
- 选中的组件名：#hudSelection 与底部状态栏 #statusSel 都【保留】（只保证显示内容随 Title 更新），左侧坐标窗口顶部也显示。
- 缩放百分比只保留一处：保留工具栏的 #zoomLabel，删除画布右下角 #hudZoom 及其更新代码。
- 小数提示简化：只保留一条汇总（"N 行含小数，已四舍五入"），去掉折叠详情列表；非法行错误仍逐行列出。
- 保留：#hudDrag（拖动中坐标）、#hudMouse（鼠标坐标）、hoverTip、右键保存坐标点（用户需要，勿动）。

## 四、通用要求
- 所有修改路径（拖动、缩放、输入、方向键、层次、重置、撤销/重做）后，列表、矩形、坐标窗口、Z、已修改标记、锁定状态都要一致（走统一的同步函数）。
- 新增的纯逻辑（Z 重分配算法、搜索匹配、CSV 新列解析/兼容旧格式、草稿序列化/恢复、16:9 判定）放进 PBILOGIC 块并补 Node 单测，边界覆盖：Z 重复、Z 不连续、置顶/置底已在顶/底、无 Z 列/无 Title 列、Title 含逗号和引号、草稿损坏/版本不符时安全丢弃、比例刚好在容差边界。
- 快捷键帮助浮层（"?"）补充：[ ] Ctrl+[ Ctrl+] L Ctrl+V。
- 性能：300+ 组件下拖动、搜索输入保持流畅。
- 不要做：多选、新建/删除矩形、读写 PBIP、把蓝图/草稿写进 CSV。

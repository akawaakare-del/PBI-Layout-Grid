## 5.1 组件不遮挡网格（微调时要看得到格子）
- 工具栏加"组件透明度"滑杆（0%~100% 填充不透明度，默认约 15%），实时生效，数值写入 localStorage 设置；边框始终清晰，选中态边框加粗。
- 网格线（含 10px 细线与主格线）绘制在组件【之上】，且 pointer-events:none，不影响点选/拖拽。
- 工具栏加"网格置顶"开关（默认开）；关闭时网格回到组件下方。状态写入 localStorage 草稿设置。
- 有蓝图底图时，网格同样可见。

## 5.2 画布区滚动条（必做）
- 画布视口出现横向、纵向滚动条（内容大于视口时），可用鼠标拖滚动条、滚轮上下滚动、Shift+滚轮左右滚动。
- 保留现有：Ctrl+滚轮缩放、空格/中键拖拽平移。平移与滚动条位置保持同步。
- 缩放后内容区尺寸 = 画布尺寸×缩放 + 四周留白（至少 200px，便于操作越界组件和边缘组件）。
- 以鼠标为中心缩放时，滚动位置同步修正，不跳动。"适应窗口"后滚动条应消失或回到起点。
- 在 1366×768、1920×1080 两种视口下验证，页面本身不得出现整页滚动条。

## 5.3 格式刷
- 工具栏加"格式刷"按钮（快捷键 Ctrl+Shift+C 取样 / Ctrl+Shift+V 应用）。
- 用法：选中 1 个源组件 → 点"格式刷"（进入刷子模式，光标变样式、按钮高亮）→ 点击目标组件，把源的【宽、高】应用到目标（位置 X/Y 不变）。
- 单击按钮 = 刷一次后自动退出；双击按钮 = 连续模式，可连刷多个目标，Esc 或再点按钮退出。
- 目标已锁定则跳过并在状态栏提示"已跳过 N 个锁定组件"。结果越界按现有越界规则处理（允许，标红）。
- 多选时：以"最后选中的为源"不适用，规则统一为：刷子模式下点击的目标全部应用；也可先框选/多选一批目标再点"应用到所选"（源=取样的那个）。
- 整次应用（含多目标）合并为一条撤销记录，Ctrl+Z 一次撤回。
- 对话方式：取样后在按钮旁显示"已取样 W×H"。

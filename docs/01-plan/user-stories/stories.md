## 验收标准（P0）
**US-01** 格式错误给出明确提示；缺字段指出是哪个组件哪个字段。
**US-02** 逻辑尺寸 1280×720；滚轮缩放（以鼠标为中心），空白处拖动平移；缩放不改坐标。
**US-03** 重叠组件点选取最上层；选中高亮；可按列表选中。
**US-04** 画布坐标（整数）随鼠标实时显示；拖拽中显示 x/y/宽/高及相对原位置的位移。
**US-05** 松手位置为 5 的倍数；不可拖出画布；原位置以虚线保留对照。
**US-06** 距其他组件边/中心 ≤ 阈值（建议 5px）时吸附并画引导线；按住修饰键可临时关闭。
**US-07** 多步撤销/重做；一键恢复为导入状态。
**US-08** 输出结构与输入一致，变更组件带 `changed:true`；一键复制。

## 待确认
1. **"5px 自动吸附"是哪一种？** (a) 坐标按 5px 为步长取整；(b) 靠近其他组件边缘/中心 5px 内自动贴齐并出引导线（类似 Figma）；(c) 两者都要。我建议 (c)。
2. 背景网格画 10px 一格，而吸附步长是 5px，这样可以吗？
3. 是否需要拖边改宽高（US-09）？严格布局下通常需要，建议提到 P0。
4. 输入/输出格式（见 PRD 第 6 节）是否可以？输出是否还要附"仅变更项"清单？
5. 成功标准目标：从 2–3 小时降到多少？
